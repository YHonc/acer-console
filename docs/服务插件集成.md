# Acer Central 服务插件管理

集成来源：用户指定的对话“规划 Acer 服务逆向与 Rust 低占用重写”，本机项目 `E:/逆向ACER`。集成的是已经安装的 Central 二进制补丁和 Rust Handle Guard，不是完整 Rust 服务替换。

## 在哪里使用

左侧“服务插件”页：

- Central：配置路径、补丁文件 SHA256、运行状态、PID、启动方式。
- 看门狗：计划任务启用状态、运行状态、最近结果、上次/下次运行时间；授权后可启用或暂停，变更前在页面确认。
- 用量：CPU 整机比例、工作集、私有提交、句柄、线程和运行时长；本页统计 CPU 时间加权均值、工作集样本均值/峰值及句柄净增长速率。
- 日志：选择查看重启/异常、轮转日志、最近检查或补丁启用记录；收起后清空显示缓存。

默认只在打开本页时查询一次；可以手动刷新，或勾选每15秒刷新。自动刷新只在本页挂载且窗口可见时工作。统计最多120个样本，切页或关闭窗口清空，进程PID/启动时间变化时重新开始。没有额外常驻采样服务，不保存长期历史。一次查询会启动短命 PowerShell 读取 CIM/任务计划，属于兼容实现，尚未宣称其开销为零。

日志默认不读取，只允许四个固定文件名；每次最多读取末尾32 KiB，界面按纯文本显示。不会自动收集整个磁盘或上传日志。日志缺失和权限错误显示具体错误。

## 管理边界

只切换已安装 `AcerHandleGuard` 任务的 Enabled 属性；不创建任务、不改参数、不立即运行任务、不重启服务、不安装/卸载/切换补丁。启用后的后续计划检查仍遵循原工具行为，达到12000句柄可能重启Central；暂停不会取消正在执行的检查。

管理操作走现有提权helper，固定枚举和任务名；先核对任务执行路径、完整参数与已安装guard的SHA256，再修改并重新读取。普通权限无法查询SYSTEM任务时显示未知，可点“授权插件管理”后再刷新。权限拒绝不会被显示为“未安装”。

插件与设备授权共用现有helper连接。点击授权不改变看门狗状态。若程序版本不同导致核验失败，控制按钮保持禁用，需要先核对新版本再更新兼容记录。

- Rust 新增固定操作/日志枚举拒绝未知参数及日志截断测试；工作区测试通过。
- Svelte检查0错误0警告，生产前端构建通过。
- 本机普通权限只读query成功识别服务配置对应的补丁哈希、PID和资源计数；任务查询返回拒绝访问，正确保留为未知。记录 `evidence/central-plugin-read-20261102.json`。
- 独立浏览器预览检查插件页导航、无数据禁用、日志展开/收起及无横向溢出；截图 `evidence/central-plugin-preview.png`。预览没有Tauri接口，不冒充实际插件操作成功。
- 启用/暂停及提权RPC端到端由用户实测；本次没有执行状态变更、重启服务或替换厂商文件。

## 用户测试

关闭旧控制台后运行新包，在“服务插件”点刷新；需要时点击授权插件管理。检查补丁状态和计数，再按需测试看门狗暂停/启用和日志查看。CPU首次为未知是预期；至少第二次有效采样才有区间占用。数字只覆盖AASSvc，不包含控制台及其他厂商进程，不是整套替代方案节省量。
