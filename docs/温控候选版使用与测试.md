# 温控候选版使用与测试

当前为开发候选，尚未完成本机曲线实测。已有功能由用户验收；测试不需要先关闭官方服务、改驱动或取消温度保护。

## 使用

1. 自行退出旧版，解压候选包，保持acer-console.exe与acer-helper.exe同目录。
2. 在“性能与风扇 → 自定义温控曲线”填写CPU/GPU温度与目标百分比。每条2–16个点，温度递增、百分比不递减。空白初始曲线没有隐藏推荐点。
3. “保存曲线”只保存到当前用户应用配置目录的thermal.json，不启动硬件控制；重启也不会自动启动。
4. 显式授权设备后，在接电且CPU/GPU温度和风扇状态可读时确认启动。运行期间手动风扇/性能模式操作被阻止，避免争用。
5. “停止并恢复自动”尝试恢复Auto；恢复未确认时显示异常并允许重试，不应将旧目标百分比当作当前实际转速。

## 行为边界

- 软件曲线运行在helper拥有的设备线程，不是写入固件FanTable。
- 降速滞回减少往返波动；双风扇作为一组遵守较慢的写入间隔。传感器错误仍立即触发停止恢复，不等限频窗口结束。
- AC离线、采样间隔异常、外部控制器改写时停止；唤醒后需显式重新启动。GPU休眠导致温度未知也会停止，不用0°C替代。
- 正常退出先恢复自动，关闭到托盘则保持会话。helper结束会尝试清理，但强杀helper、系统崩溃或WMI永久阻塞不能保证恢复。
- 官方应用仍可能改写风扇；本程序检测到冲突后停止，不能宣称独占固件控制。
- 精确CPU/GPU瓦数控件尚未开放，官方性能模式不等同于PL1/PL2/TGP设置。

## 用户反馈项

按需逐项测试并记录，不要求现在拔电源或压测：

|项目|记录|
|---|---|
|保存后重新打开|曲线点是否保留；是否仍保持未启动|
|启动与读回|CPU/GPU温度、目标百分比、实际RPM、是否出现恢复错误|
|停止恢复|是否显示Auto恢复确认；官方/本软件读回是否一致|
|曲线运行中手动改风扇/性能模式|是否明确阻止冲突|
|退出及托盘|正常退出是否恢复；托盘是否保持运行|
|以后方便时电源/睡眠切换|是否停止并要求重新启动；是否有错误日志|

界面截图里的40/90°C与70/100%是输入验证样例，不是本机推荐曲线。当前百分比物理响应仅有早期70%点证据，不能把完整范围都算作已实测。
