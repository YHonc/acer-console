# Rust 控制台路线

2026-11-01，规划版，尚未实现。首个适配对象仅 PHN16-71 / BIOS V1.18；升级BIOS后重新验证能力。

## 决策

Rust负责硬件协议、状态、托盘和规则；Tauri 2承载桌面窗口；Svelte 5 + TypeScript + Vite负责界面，采用原生CSS变量和小型自有组件集。不引入SSR、Node后台服务或大型仪表盘组件库。当前项目没有既有Cargo/frontend/token系统，按新项目建立。

窗口关闭时计划销毁WebView，Rust保留托盘；再次打开创建窗口并读取快照。必须实测WebView子进程是否释放，不能把隐藏窗口当作释放内存。若Tauri无窗口生命周期无法达到预算，再评估独立原生Rust托盘宿主，不提前增加多进程复杂度。

## 结构

- crates/acer-protocol：参数编码、解码、返回码、机型能力表；纯函数可测试。
- crates/acer-device：Windows WMI/COM访问；固定工作线程管理COM连接与串行请求，不在采样中启动PowerShell。
- crates/control-core：状态快照、操作队列、事件订阅、配置与规则。
- apps/desktop/src-tauri：Tauri命令、托盘、单实例、窗口生命周期。
- apps/desktop/src：Svelte视图和组件、tokens.css。
- tools/probe：只读命令行核验；fixtures：脱敏原始返回值。

权限先测普通用户读取和写入。仅当实际需要提权时引入小型Rust helper，前端始终普通权限。helper用限制当前用户/管理员的命名管道及固定命令枚举，不接受任意WMI方法、地址、命令行。安装和授权独立于日常窗口启动。

命令建议：get_capabilities、get_snapshot、set_profile、set_fan_mode、set_lighting、restore_previous。前端接收状态事件。每次写入经过能力检查、参数校验、串行执行、读取确认；返回applied/failed/unconfirmed，不把API返回成功等同硬件已生效。设备不支持的设置显示原因；读取失败显示未知及上次更新时间。

## 阶段与完成门槛

|阶段|实现|完成门槛|
|---|---|---|
|P0 基线|官方进程树及资源采样，安装清单、任务和服务备份|能重现同一负载，保留原始数据|
|P1 协议|方法签名、官方组件静态定位、Rust只读探针|温度/转速/模式逐项与官方及原始值对照；权限错误正确显示|
|P2 写入|先灯光、风扇Auto/Max，再性能模式|每项有原值、返回码、读回和恢复记录；AC/DC限制已验证|
|P3 最小产品|概览、散热、灯光、设置、托盘|真实设备端到端操作通过；关闭窗口不影响已验证的硬件自动控制|
|P4 替代上线|备份并禁用PredatorSenseLauncher、自启动新应用|重启、登录、睡眠恢复、插拔电源通过；一键恢复官方任务|
|P5 优化|按需采样、窗口释放、可选AC/DC规则、自定义风扇|资源实测达标；规则不反复写入；自定义风扇单独验收|

官方服务逐个做依赖实验；先关闭官方前端，再核对WMI与热键等能力。必要服务继续保留。首版不做EC直接写、BIOS编辑、超频或用户态闭环风扇曲线。后者需要额外故障回退设计，不和硬件Auto模式混淆。

## 功能优先级

首版：温度和风扇转速、当前模式、AC/DC状态；可验证的模式切换；Auto/Max；键盘静态灯光/亮度；托盘、恢复、日志。若温度接口未验证，不用假值填充。

第二版：自定义风扇百分比、更多灯效、充电限制、刷新率、电源规则。每项以本机协议证据为准，未确认接口的充电限制不承诺交付。

退出语义：关闭窗口=留托盘；明确退出=停止规则和采样，并尝试恢复本应用改变的临时风扇状态；失败须反馈。不假定进程异常退出能执行清理。首版优先使用设备自身自动控制。

## 设计方向

参考Apple HIG的清晰层级、一致交互和可访问性，用Windows原生标题栏与操作习惯。主窗口初拟960×680，可缩放。左侧导航：概览、散热、灯光、设置。概览突出当前模式与CPU/GPU状态，详细历史按需展开。托盘承担日常快速切换。

浅色和深色跟随系统；中性背景、单一蓝色强调、分组设置行；文字和状态优先。字体使用Windows系统字体，数值等宽；不打包Apple专有字体/图标。使用统一SVG图标。间距4/8/12/16/24/32，正文14–15px、辅助12–13px、页面标题24px；这些是项目初始设计值，待原型验证。圆角8–12px按组件分级。避免整屏模糊、持续动画与炫光。

交互：已应用、应用中、失败/未确认三种状态明确；硬件切换完成前不提前显示成功。键盘焦点清晰、完整Tab操作、支持屏幕阅读器、减少动态效果、高对比度与125/150/200%缩放。短过渡初拟120–180ms，只用于状态变化；减少动态效果时关闭。

## 资源预算与测量

以下是设计目标，不是当前成绩：托盘稳定后总私有工作集≤50MiB，10分钟平均CPU≤0.2%；打开窗口总私有工作集≤200MiB、稳定平均CPU≤1%；暖启动可交互≤1秒、首次≤2秒。总量包括本应用关联WebView子进程和helper；共享运行时另记，不从报告中藏掉。与官方比较时同时报告必须保留的Acer服务成本。

前台可见时1–2秒采样；后台无监控需求时停止遥测，必要状态事件驱动，兜底慢轮询。历史数据只保留有限内存环形缓冲；配置小JSON原子写入，日志轮换。温度采样不作为首版风扇控制回路。

同机同电源同负载各测官方界面、官方后台、新界面、新托盘；预热后记录10分钟均值/P95和峰值，至少3轮。Release包计量，不用开发服务器。能否达到预算由P3实测决定。
