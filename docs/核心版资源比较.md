# 核心版资源比较

## 已验证的采样流程

2026-11-02 为 `scripts/Measure-Resources.ps1` 增加 `-Target official` 与 `-Target replacement`。两者均纳入 AcerCentralService、AcerLightingService、AcerAgentService、AcerHardwareService 及后代进程；替代版额外选中 acer-console 和 acer-helper，其 WebView 后代自动纳入。

预设不允许与自定义进程选择混用。应用未运行时立即报错，避免将单独服务占用误报成应用占用。当前替代版未运行，已验证此拒绝路径。

官方版只读试采集记录：`evidence/resources-core-collector-smoke-20261102.json`。15.58 秒、5 次采样、0 个采集错误，私有工作集有 5 个有效样本；实际纳入 PredatorSense、四项 Acer 服务进程及 OpenRGB。此记录仅验证采样脚本，不构成性能对比。

## 正式比较步骤

在用户方便操作窗口时，对官方版与统一核心 Release 分别测量：相同窗口状态、相近系统负载、相同监控页面、同样预热时间。开窗与托盘分组比较，不交叉比较。每组至少采样 600 秒，记录电源状态、版本路径及构建哈希。

```powershell
# 先将官方界面置于所记录的状态。
./scripts/Measure-Resources.ps1 -Target official -DurationSeconds 600 -Scenario 'official-visible-overview' -OutputPath './evidence/resources-official-visible.json'
# 关闭官方界面并启动待测核心包，保持相同观察条件。
./scripts/Measure-Resources.ps1 -Target replacement -DurationSeconds 600 -Scenario 'replacement-visible-overview' -OutputPath './evidence/resources-core-visible.json'
```

托盘组另存文件并准确填写 Scenario。官方后台不能等同于官方托盘，必须实际确认状态。报告总私有工作集、CPU 时间加权均值以及进程清单；保留服务计入两边总量，并单独展示其占用。未采到的进程与生命周期之间丢失的 CPU 仍是脚本已记录的限制。

上述采样记录属于采样工具验证阶段。其后Gemini核心版曾启动，但桌面验收由用户Esc中止；目前已交付服务插件版，功能测试由用户执行。仍无最新包的同条件资源比较结果，预算为待验证目标。服务插件页仅统计AASSvc，不可作为整套替代应用的节省量。
