# 精确功耗控制实施

更新：2026-11-04。目标：在 PHN16-71 / BIOS V1.18 上交付 CPU、GPU 精确功耗控制及可验证恢复。当前完成 CPU 单次 MSR PL1 写入/恢复，GPU 进入只读桥实机验证准备阶段。

## 已完成

- CPU：实现 IPF ABI、会话发现、PL1/PL2 读取、PPCC 解析及事务层；实现 PawnIO MSR 读取、精确编码、原值保存、读回、冲突检查和恢复。
- 探针：提供 cpu-power、gpu-power、msr-power 独立命令，恢复记录绑定设备身份，创建时禁止覆盖并刷盘。
- 实测：IPF 与 MMIO PL1 为 80W；MSR PL1 为 100W；PL2 为 157W，PL1 时间窗 56 秒。PawnIO 2.2.0 已获批安装。
- CPU 单次试验：100→95→100W，目标读回、自动恢复及独立复读成功。详见试验结果。
- GPU：NVML 配置上限读取返回 NOT_SUPPORTED；范围为 5–140W。NVAPI 策略查询返回空条目。已从完整 21 张 SSDT 中定位 NPCF 字段。
- GPU 只读桥：AML、MOF、Windows 客户端及 OpenCore 四文件候选已生成；编译、文件校验、ocvalidate 和独立审查完成。
- 最近一次相关离线测试：167 项通过。试验后增加的全寄存器基线检查已通过离线测试，实机试验覆盖此前运行版本。

## 当前待办

2. 获批后制作外部启动介质，由用户安排一次性启动，验证 Windows WMI 类及 NPCF 原始读数。
3. 根据 GPU 字段语义和可读原值实现同字段写入与恢复，再安排独立写入验收。
4. 补齐 CPU 两层限制关系、PL2/时间窗及持续运行、退出和异常恢复验证。
5. 完成受限权限接线、正常 UI、发布候选及使用/恢复说明。

95W 高于已读到的 MMIO 80W，本次试验验收的是 MSR 写入与恢复。实际负载功率和长期维持仍待验证。IPF 的 PPCC 返回 3703，PL2 时间窗返回 2404，当前能力路径不能支持完整 IPF 控制。
