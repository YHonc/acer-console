## 最终目标

交付能在用户 Acer Predator PHN16-71 上日常替代官方 PredatorSense 的 Rust 桌面控制台。前端 Svelte + Tauri，采用苹果式清晰、一致、克制与可访问性设计，保持Windows操作习惯。实测降低资源占用，提供可运行交付包、操作说明、恢复方案及逐项验收证据。

## 功能范围

1. CPU/GPU温度、风扇转速、性能模式、电源和电池状态监控。
2. 本机官方支持的性能模式及AC/DC限制。
3. 风扇自动、最大、自定义控制，CPU/GPU分别控制；自定义能力以官方实际功能为参照。
4. 本机键盘灯光：开关、亮度、颜色、分区和官方支持的灯效。
5. 本机存在的充电限制及其他官方核心设备设置；先建立官方功能清单，再逐项映射。
6. 托盘快捷操作、配置保存、关闭窗口保留低占用后台、明确退出、可选开机启动。
7. 电源切换规则、睡眠唤醒恢复、错误反馈与诊断日志。
8. 备份并取消官方界面自动启动；验证后保留必要厂商组件，提供恢复官方启动与设置的入口。

功能状态必须区分：已验收、已实现待实测、协议待逆向、权限/环境受阻、硬件明确不支持。不得把未找到协议归为不支持。确实无法实现时，记录已做的调查和具体障碍并向用户报告，不静默删减功能。

## 缺失功能的固定处理顺序

先检索GitHub可用实现，核查源码、许可证、机型和参数。没有合适实现则逆向本机官方PredatorSense：机型配置和Electron资源 → 服务/IPC调用 → DLL与WMI协议 → 必要时动态观察。逆向skill和分析工具仅为辅助手段，不代替实现。所有硬件实验由主对话统一调度，避免多代理同时写入。
