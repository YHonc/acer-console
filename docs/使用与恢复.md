# Acer Console 使用与恢复

适用当前开发版本及本机 Acer Predator PHN16-71 / BIOS V1.18。完整交付状态以《目标与验收.md》和《集成验证记录.md》为准。

2026-11-02 核心版范围：保留监控、性能模式、风扇、键盘灯光、电池限充、托盘、配置、电源规则、自启动与官方启动恢复。电池校准已取消，开机图片入口已移除，不需要执行校准。当前候选包已接入用户选择的 Gemini/daisyUI 界面；功能实测由用户负责，构建与浏览器检查不代表最终实机验收通过。新增“服务插件”页用于管理现有 Central 补丁/Handle Guard、按需查看日志和采样资源用量，详见《服务插件集成.md》。

## 启动与授权

将 `acer-console.exe` 和 `acer-helper.exe` 放在同一目录，运行前者。发布版本内置前端，不需要启动 Vite、Node 或开发终端；Windows 需要 WebView2 运行时。

点击界面的设备授权入口，由 Windows 处理提权。主窗口保持普通权限，helper 只接受固定设备控制与官方启动管理操作。需要同一个 Windows 用户完成授权；使用另一个管理员账户的凭据不受当前权限链支持。

未授权、连接中断或读取失败时，界面显示未知或具体错误。先重新授权和刷新，再使用控制。颜色、风扇百分比等编辑值只有应用并读回确认后才算生效。

## 日常控制

- 概览：查看 CPU/GPU 温度、转速、供电状态及当前性能模式。接电模式已实测安静、均衡、性能、极速；电池模式仍待实机验证。
- 散热：自动、最大、自定义双风扇目标。百分比表示设置目标，不等于测得的物理占空比；RPM 是实际转速读数。切换自动后旧的自定义目标可能仍被固件缓存。
- 灯光：当前已实测静态亮度与四区颜色。动态效果的开放状态以当前能力检查为准。
- 电池保护：开关已做本机读回与恢复验证；具体充电停止阈值尚未通过实际充电过程测量。
- 设置：选择主题、采样间隔、关闭窗口行为及退出恢复。电源规则默认关闭，保存规则先建立当前基线，之后的电源切换才触发目标。

## 托盘和退出

开启“关闭到托盘”后，关闭窗口释放 WebView，后台继续保留已启用的规则与授权连接。托盘可打开控制台、切换风扇/性能模式和明确退出；快捷操作使用同一套能力检查、写入和读回逻辑，不自动重新提权。

“退出恢复”恢复本次会话首次风扇操作前记录的控制状态。启用时须能读到可恢复状态。它不等于恢复全部设备设置，也不覆盖断电、强制结束进程或系统崩溃。恢复失败时程序保留窗口与错误，可重新授权后重试，或明确选择不恢复退出。

## 开机启动与官方控制台

新应用的开机启动只注册当前用户的 `AcerConsole` 项，命令固定为当前程序加 `--tray`。应先把发布目录放到长期保留的位置，再开启自启动；移动目录后重新设置。

管理官方启动项前先授权，再在设置中备份。操作只针对 `\PredatorSenseLauncher` 计划任务，禁用不会卸载官方软件，也不会停止 Acer 服务。恢复使用已验证的原始备份，任务定义发生变化时会拒绝盲目覆盖。

目前官方任务的原生及提权RPC禁用/恢复往返均已通过，并已恢复为启用。正式替代切换仍待完整验收。

保留音效功能需要 Acer Agent/DTS 组件。取消官方界面自启动不等于可以卸载全部厂商服务。

## 数据与回退

设置及启动任务备份位于 `%APPDATA%\local.phn16.acerconsole`。需要保留恢复能力时不要删除此目录。

如需回到官方控制台：在设置中恢复官方启动项、关闭 Acer Console 的开机启动，确认风扇处于希望保留的状态后退出，再打开官方 PredatorSense。官方启动恢复操作不会恢复灯光或性能模式；这些可在官方界面重新选择。

拔插电源、手动睡眠唤醒和实际重登测试仍待用户方便时完成。当前说明不将这些项目视为已经通过。
