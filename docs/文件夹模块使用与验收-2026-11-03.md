# 文件夹模块使用与验收

## 本轮交付形态

Device Center作为完整独立程序放在`modules/device-center/`，Acer Console通过module.json绑定与启动。鼠标、键盘、挂灯、云连接、托盘等功能在Device Center自己的窗口中使用，不要求将外设协议合入Acer核心。原项目`D:/ChatGpt/DeviceCenter`保留。

模块带当前源码白名单归档、许可证、主程序与所需DLL。全部模块功能仍以原项目实际支持的设备/协议边界为准；“完整模块”表示完整原程序，不表示支持原项目尚未实现的设备字段。

## 使用

1. 解压宿主交付包，保留acer-console.exe与acer-helper.exe同目录；附带modules/device-center文件夹。
2. 在“服务插件 → Device Center外设中心”选择“选择模块文件夹”，选中包含module.json的device-center目录。
3. 检查模块版本、路径和校验状态；选择文件夹不会启动程序。
4. 点击“启动设备中心”并确认，在独立窗口使用外设功能。已在运行时，从原应用托盘打开或退出；宿主不强杀进程。
5. 模块升级改变文件/清单后需重新绑定。清单SHA256用于一致性检查，不是厂商签名认证。

## 自由拆分与删除

- 先在本控制台关闭其创建的Device Center自启动项，再从Device Center托盘退出。
- 在宿主点“解除绑定”并确认：只移除宿主绑定，程序、原账号与设备设置保留。
- 若不再需要，用户可自行删除完整模块文件夹；保留它则可再次绑定。
- 不删除D盘原项目、不读取或清理米家凭据。账号数据的自动清理不在本次实施范围。
- 删除模块文件夹后Acer核心仍可运行；若未先解绑，模块会显示失效，可关闭自启动后解除失效绑定。

## 同步抖动修复

顶部刷新/同步中文案使用同一个inline-grid单元格，以较长文案确定宽度，仅切换透明度；图标旋转，禁用opacity .6，状态胶囊不压缩/换行，数字等宽。浏览器呈现层交替切换3轮，全部顶部元素矩形一致，按钮宽97px。证据`evidence/module-integration-20261103/sync-layout.json`；这是呈现验证，不是硬件同步成功证据。

## 授权问题

本轮仅诊断，见`授权生命周期诊断-2026-11-03.md`。未改变UAC、broker会话或保存授权凭据。不得将模块导入功能误认为实现了永久授权。

## 验证边界

Device Center前端构建0错误0警告、Rust Release成功；原GNU构建有未使用函数与重复manifest/ICON资源警告，详见`DeviceCenter模块打包说明.md`。未启动新模块或登录账号、未验证真实设备设置。原生运行及硬件功能由用户测试。

宿主目录绑定与解除使用隔离临时配置验证，结果落在`evidence/module-integration-20261103/`；实际用户绑定、自启动与删除未操作。最终宿主构建与组合包哈希以本轮build-manifest和module.json为准。
