# 核心版功能测试单

按用户约定：功能实测由用户进行，代理负责其他开发和交付工作，以及根据反馈修复问题。

## 使用哪个版本

当前测试包：`artifacts/AcerConsole-AppleUI-20261106`（同名 ZIP）。旧包已删除，勿混用其他位置解压的旧版 EXE 和 helper。文件夹模块使用步骤见[模块验收说明](文件夹模块使用与验收-2026-11-03.md)，温控新增项见[温控使用与测试](温控候选版使用与测试.md)。

运行 `acer-console.exe`，保持 `acer-helper.exe` 在同一目录。本版为 2026-11-06 接入的 Apple 风格界面（见 [UI 接入目标](UI接入目标-2026-11-06.md)）。本版需额外留意：窗口拖动与贴靠、页面与子页切换动画、真实读数下的数字/仪表/曲线变化、应用设置后“当前 / 待应用”标签是否随设备读回更新、深浅主题切换。电池校准与开机图片不在范围内。

## 建议先测试这些

本版UI反馈修复：数字逐位0.7s滚动；温度变化不足1度保持显示，转速按10 RPM取整且显示差不足20保持；开关仅一个旋钮；操作记录在按钮上方展开，长记录内部滚动、Esc或外部点击关闭。切换页面/插件时有入场动画，轮询刷新不应重播或重置开关、折叠状态。无真实读数时显示破折号是预期行为。

独立待确认的窗口项目：标题栏空白拖动、双击最大化/还原、拖到屏幕边缘贴边、边缘缩放、最小化后从任务栏恢复。此前自动化未取得这些项目的可靠结果；用户已选择亲自测试，尚未收到结果。

## 如何反馈

直接回复：**页面/功能 → 操作 → 实际结果 → 期望结果**。有错误提示时附原文；能截图时附截图即可。无需先完成整张表，有问题就反馈。

代理已完成的构建、浏览器检查与文件哈希不代表这些功能已由用户测试通过。

## 11-07 新包功能测试

只使用最终 11-07 构建包，避免与 11-06 EXE、旧 helper 或旧 Device Center 模块混用。所有真实硬件写入均以用户逐项批准为前提；每项先保存原状态。读回只证明设备接受值，物理效果需单独观察。
