# Apple 风格 UI 重构预览（2026-11-05）

打开 `preview.html` 即可预览，单文件，可离线运行。所有读数都是**模拟数据**，用来评审视觉和动效，不代表设备状态。右下角“预览控制”不属于产品界面。

## 覆盖范围

- 设备总览：CPU/GPU 圆环仪表、运行状态列表、快捷操作。
- 性能与风扇：性能模式草稿/当前/应用、风扇实时状态、风扇模式与自定义滑块、温控曲线图表编辑（启动确认、运行时锁定手动控制）。
- 设备设置：键盘灯光（8 种灯效、动态参数、单色、四区静态）、硬件辅助与电源（电池保护、USB 关机供电、电源切换规则、厂商外设与音效）、应用与系统（主题、采样、登录启动、窗口偏好、官方联动、能力折叠）。
- 服务插件：分为“Acer 服务保护”和“Device Center 外设”两个平级子入口（见下文）。
- 状态场景：正常 / 读数过期 / 待授权 / 断线。URL 参数：`?page=fan&tab=aux&scn=stale&theme=dark&pv=1`；`page=acer`、`page=dc` 直达两个子页（旧链接 `page=plugin&plugin=acer|devices` 仍可用）。
- v1 备份：`preview-v1.html` 已于 2026-11-07 移到 `待删除-20261107/design/`，也可从 Git 历史（提交 0cd24f3 及更早）取回。

## 设计规则

- 配色：浅色 `#f5f5f7` 底、白色分组卡片、0.5px 分隔线；系统蓝作为强调色，绿色/橙色/红色分别表示已确认、草稿/过期、错误或断线。深色模式使用分层灰，不是简单反色。
- 层级：28px 大标题；滚动后工具栏显示毛玻璃和小标题。分组标题在卡片外，说明文字使用次级色。
- 状态语义：每组右上角的标签区分“当前（设备读回）”和“待应用草稿”。分段控件中，橙点标示设备当前值；选中底板表示草稿。未知值显示破折号，过期时置灰。

## 动效令牌

| 令牌 | 参数 | 时长 | 用途 |
|---|---|---|---|
| snappy | 阻尼 0.88，响应 0.30s | 370ms | 分段滑块、导航高亮、弹窗、按压回弹 |
| smooth | 阻尼 1.0，响应 0.36s | 490ms | 滚动数字、折叠高度、曲线变形、仪表 |
| bouncy | 阻尼 0.68，响应 0.36s，过冲 5% | 550ms | 开关、顶部提示、状态标签 |
| gentle | 临界阻尼 | 680ms | 页面进入，子元素依次延迟 26ms |
| exit | ease-in | 120–200ms | 页面离开、提示/弹窗/浮层关闭 |

弹簧曲线用阻尼振子公式采样，写成 CSS `linear()`。这是本项目的近似实现，不是 Apple 官方参数。悬停只改变颜色，不做位移。只有交互或真实值变化才会触发动画，不增加常驻循环；唯一的循环是请求进行中的转圈指示器。开启“减少动态效果”后只保留 140ms 淡入。主题切换使用 View Transition，从按钮位置圆形展开。

## 2026-11-06 新增规则

### 滚动条（全局）

- 仿 macOS 悬浮细条：平时隐藏，滚动或指针进入可滚动区域时出现，停止 1 秒后用 200ms ease-in 淡出。滑块平时 6px，悬停或拖动时以 snappy 加宽到 10px，同时显示浅色轨道。浅色和深色主题分别使用 `--sb-thumb`、`--sb-thumb-hover` 和 `--sb-track`。
- 方案：用覆盖层实现。原生滚动条全局隐藏（`scrollbar-width:none` 与 `::-webkit-scrollbar{width:0}`），由一个 `position:fixed` 的 `.sb` 元素绘制，并支持滚轮、拖动和点击轨道跳转。
- 不用 `::-webkit-scrollbar` 加类名切换的理由：
  1. WebView2 新版 Chromium 中，只要元素设置了标准属性 `scrollbar-width/scrollbar-color`，`::-webkit-scrollbar` 样式就会失效，两套写法互相干扰。
  2. 伪元素不能做宽度过渡和透明度过渡，6→10px 和淡出只能硬切。
  3. 原生滚动条会占用布局宽度，显示和隐藏时内容会横向跳动。覆盖层不占宽度，因此不再需要 `scrollbar-gutter`。
- 正式版建议做成一个 `OverlayScrollbar` 动作或组件，挂在 `.main`、弹出层和日志框上。滚动条属于装饰层，设 `aria-hidden`，键盘滚动行为不变。

### 侧栏展开/收起

- 切换按钮放在标题旁；快捷键 Ctrl+B（macOS 为 ⌘B）。收起后是 64px 图标栏，宽度变化使用 smooth（490ms）。文字只做淡出（120ms ease-in），展开时延迟 110ms 淡入；所有文字 `white-space:nowrap` 并被裁切，不会被挤压换行。
- 收起时，指针悬停或键盘聚焦图标会在右侧浮出文字提示；在提示之间移动时立即切换，不再等待。底部的机型和 BIOS 收为一个连接状态点，悬停可看到全文。
- 窗口宽度小于 900px 时自动收起；回到 900px 及以上时恢复手动选择的状态。只有手动切换会写入 `localStorage`（`acer-preview-sidebar`），首帧前读取，避免闪动。
- 减少动态效果时直接切换，不做宽度过渡。

### 读取不锁操作

- 读取或同步只驱动状态显示：刷新按钮显示转圈但仍可点击，重复点击合并为同一次请求；所有控件保持可编辑。
- 读回结果按项合并：没有草稿的项直接跟随读回；有草稿的项只更新当前值（分段控件橙点、StatusTag“设备 …”），不覆盖草稿。
- 冲突：读回值与上次已知值和草稿都不同时，在该组内展开橙色提示行“设备已变为 X”，提供“保留草稿”和“采用设备值”两个按钮。草稿改回当前值或应用成功后，提示自动收起。
- 锁定只针对正在写入的单项：即时开关在写入期间显示 `.sw.pending` 并禁用自身，其余控件不受影响。“应用”按钮在请求期间显示转圈。安全条件锁保持不变（温控曲线接管风扇、未授权、断线）。
- 预览控制里的“设备端改动并同步”按钮会模拟外部改动并触发一次同步，可在性能模式页和外设页演示冲突。所有数据均为演示数据。

### Device Center 外设页

- 入口是侧栏“服务插件”下的子项，服务插件页另有一行跳转。页面使用原生 `.group/.row/.sh/.tag`、分段控件、开关和 StatusTag，取代“选择模块文件夹 + 启动独立窗口”的样式。
- 模块：显示已发现的 `modules/device-center v0.1.1`、后台进程和协议版本。文件哈希变化时展开“模块文件已变更，确认后启动”，确认前模块不运行，外设控件全部置为未知。“控制台退出时保持后台运行”默认关闭。模块文件夹不存在时，侧栏入口收起消失（200ms ease-in），恢复时展开出现。
- 设备：ATK F1 鼠标、KX75 键盘、小米挂灯 1S，显示连接状态和电量；电量未知时显示“—”。
- 鼠标：DPI 档位、当前 DPI、回报率、按键映射入口。鼠标灯效暂无协议，只写一行“鼠标灯效：暂不支持”，不放控件。
- 键盘：回报率、休眠时间是草稿，需点击“应用”；低延迟、Mac 模式、Win 锁是即时开关，读回未知时显示“—”而不显示开关。灯效包括模式、亮度、速度、单色或多彩；选择单色时展开 RGB。
- 挂灯：开关、亮度、色温。连接设置包括 IP（带格式校验）和 Token（只显示末 4 位，更换时使用密码输入框，并校验 32 位十六进制）。
- 二期功能（宏、按键层、小米云登录、鼠标性能项）折叠在“即将支持”中，只有标签，没有可操作控件。

## 2026-11-06 第二轮修改

### 服务插件拆分

- “服务插件”是带图标的父项，下面有两个平级子入口：“Acer 服务保护”（内置，包括 Central 句柄修补、Handle Guard、日志）和“Device Center 外设”（模块）。原来服务插件页里的分段切换已去掉。
- 选择：点击“服务插件”直接进入第一个子页“Acer 服务保护”，不设单独的分组页。理由：父项保留了图标，所以侧栏收起后仍有可点击的目标；总览页的“服务插件”快捷入口和旧链接也能直接落到实际内容，不会出现一个只有两条链接的空页面。
- 模块被删除时，只有“Device Center 外设”入口收起消失，“Acer 服务保护”不受影响。如果当时正在外设页，会回到 Acer 服务保护。侧栏收起后，两个子入口都显示图标，悬停或聚焦时有文字提示。

### 设备自定义顺序

- “设备”列表每行开头有把手。拖动时，被拖的行浮起并跟随指针，其他行以 snappy 弹簧让位；松手后落位。也可以用键盘：聚焦把手后按 ↑ ↓（Home/End 移到首尾）。换位以 snappy 弹簧过渡，焦点留在原把手上，并通过 `aria-live` 播报“移到第 N 位”。
- 下方各设备的设置分组（鼠标、键盘与键盘灯效、挂灯与挂灯连接）跟随同一顺序排列。顺序存在 `localStorage` 的 `acer-preview-dev-order` 中。新设备追加到末尾；已断开的设备保留原位置，状态显示“已断开”，读数和开关显示“—”，并且不参与读回。
- 开启减少动效时直接换位，不播放位移动画。
- 预览控制里的“新设备接入”和“KX75”开关用来演示追加和断开。

### 弹出按钮（替换所有原生 select）

- 原生 `select` 保留为隐藏的数据模型，原有的 `change`/`input` 监听不变。旁边插入 `.popbtn`：显示当前值和 ⌃⌄ 图标，按钮宽度取最长选项，切换选项时宽度不跳动。
- 菜单使用圆角 10px、`--shadow-menu` 阴影和半透明模糊背景（`--menu-bg`，浅色、深色各一套），当前项前打勾，悬停或键盘移动时以系统蓝高亮。弹出时当前项与按钮对齐（macOS 行为），上下空间不够时改为在按钮下方展开，必要时限制高度并允许滚动。弹出用 snappy，收起用 150ms ease-in；减少动效时直接移除。
- 键盘：在按钮上按 ↑、↓、空格或回车打开菜单。菜单内 ↑ ↓、Home、End 移动，回车或空格选中，Esc 或 Tab 关闭，焦点回到按钮。输入首字母可跳转（支持中文选项的拼音首字母，700ms 内连续输入合并匹配）。点击外部或滚动页面会关闭菜单。
- aria：按钮带 `aria-haspopup=listbox`、`aria-expanded`、`aria-controls`；菜单是 `role=listbox` 并用 `aria-activedescendant` 指向当前高亮项；选项是 `role=option` 并带 `aria-selected`。
- 有设备读数的选项用橙点标出设备当前值，并附读屏文字“设备当前值”（DTS 音效、键盘休眠、键盘灯效模式）。没有读数时按钮显示“—”，此时没有勾选项。

### 模块状态（2026-11-07，对应 `docs/DC-IPC协议-v1.md` v1.0.2）

- 模块分组的标签和状态行覆盖契约第 7 节的全部状态：运行中、启动中、重连中、已停止、被其他实例占用、协议不兼容、异常退出，以及原有的待确认（文件变更）。
- 状态行沿用冲突行的结构，按严重度分三种底色：
  - 灰底（`.conflict.info`）：启动中、重连中、已停止。前两项用转圈表示进行中。
  - 橙底：被占用。
  - 红底（`.conflict.er`）：协议不兼容、异常退出。
- 状态行的操作按钮：
  - 已停止：启动模块。
  - 异常退出：重新启动。
  - 被占用、协议不兼容：重新检测。控制台不会强行接管其他实例。
- 只有“运行中”有外设读数。其余状态下，设备行显示“状态未知”，电量显示“—”，应用按钮不可用；异常退出后也不显示旧读数。
- 退出时后台保持失败：开启“控制台退出时保持后台运行”后，如果没能通知模块继续运行，弹出确认框“未能让模块留在后台”，控制台不退出。按钮为“暂不退出”和“停止模块并退出”（危险样式）。`confirmDialog` 因此新增 `cancel` 文案参数。
- 预览控制：“DC 模块状态”下拉框切换各状态，“退出失败”按钮弹出上述确认框。“动效令牌”说明改为折叠，避免面板遮挡页面。
- 检查脚本：`check_dc_states.py`，覆盖浅色和深色下 6 个状态的标签、状态行、未知读数、应用按钮禁用和溢出，以及启动恢复、退出失败弹窗。截图：`shots/feature-dc-reconnecting.png`、`feature-dc-error.png`、`feature-dc-exitfail.png`。
