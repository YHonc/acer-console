# Apple 风格 UI 正式接入目标

2026-11-06。用户已认可 `design/apple-redesign-20261105/preview.html` 的动画和视觉，要求将其接入正式页面，同时更新过时文档、清理无用文件，并提交一次 git。

## 依据

- 视觉与动效基准：`design/apple-redesign-20261105/preview.html`（CSS 第 1–9 节、JS 中各组件行为），以及同目录的 `README.md` 动效令牌表。
- 预览里的“预览控制”面板、模拟数据、慢放倍率 `--ts` 不进入正式版（正式版 `--ts` 固定为 1，可直接去掉该变量）。

## 必须保持

- 所有 `api.*` 调用、权限判断、草稿/读回/过期/未知语义、确认弹窗文案含义、错误与日志可追溯性不变。不新增后端命令，不改 Rust/Tauri 配置。
- 未知值显示“—”，不伪造读数；温控曲线**不预填任何温控点**（预览中的示例曲线只是模拟）。
- 动画仅因交互或真实值变化触发；不新增轮询、常驻动画循环。定时器与观察器在销毁时清理。
- `prefers-reduced-motion: reduce` 下去掉位移、缩放、回弹，只保留约 140ms 淡入。
- 键盘可达、焦点可见、禁用态可辨，折叠内容收起时 `inert`。

## 共享契约（由 A 提供，其余代理直接使用）

- `tokens.css`：预览中的颜色、字体、阴影、圆角、`--spring-snappy/smooth/bouncy/gentle`、`--ease-out/--ease-in`、`--d-press/fast/base/snappy/smooth/bouncy/gentle` 令牌，浅/深两套主题（`:root[data-theme="dark"]` 与跟随系统）。旧变量名（`--secondary --text --line --raised --muted --danger --success --warning --fl --divider --surface --accent` 等）保留为新令牌的别名，避免未迁移的样式失效。
- 全局类：`.group .row .row-l .row-v .row.foot .pad .sh .hint .tag(.ok/.draft/.er) .btn(.primary/.danger/.plain/.icon) .select .num .slider .chip .dot(.ok/.wn/.er) .spinner .sq(.blue/.orange/.gray/.green/.indigo/.pink)`，含义与预览一致。旧类 `.card-group .row-item .row-label .sec-title .btn-pill .panel .list-row .setting-row .notice .banner-notice` 等暂时保留并映射到新外观，接入完成后可删除确认无引用的旧类。
- 组件：
  - `SegmentedControl`：新增可选 `current?: string`，非选中项若等于 `current` 显示橙点；新增可选 `size?: 'regular' | 'small'`、`block?: boolean`。原有 props 保持兼容。
  - `Switch`：新增可选 `pending?: boolean`（转圈并半透明）。
  - 新增 `ui/Collapse.svelte`：`{ open: boolean; children: Snippet }`，0fr→1fr 高度动画，收起时内容 `inert`。`Disclosure` 改用相同动画，外观同预览 `.disc`。
  - 新增 `ui/StatusTag.svelte`：`{ text: string; kind?: 'ok' | 'draft' | 'er' | '' }`，文本或类型变化时重放 bouncy 弹出。
  - `TopToast`、`ConfirmDialog`、`LogPopover`、`TemperatureGauge`、`AnimatedNumber/RollingNumber`：保持现有 props，换为预览外观与曲线。`TemperatureGauge` 未知时显示细破折号并隐藏单位。
